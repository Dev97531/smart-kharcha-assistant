# Project Memory

## Core
Smart Kharcha with AI: Mobile-first personal finance app.
Local-first architecture for instant performance; Supabase + Google OAuth for cloud sync/backup.
Committee (Chit Fund) feature is cloud-synced (not local-first) with realtime updates.
Premium glass-morphism UI. Light: hsl(220 16% 96%) bg. Dark: layered grays.
Multilingual support: English, Hindi, Auto (Hinglish) syncs UI & AI.
Explicit user confirmation required before saving ANY records or dates.
